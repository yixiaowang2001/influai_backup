## CoT
- 维护一个AI用户的数据库，包含生成的userid，username，态度，创建时间。 
  - 总数取决于人类用户粉丝初始数量，具体每个态度有多少，取决于一开始自然语言设定的分布（或者是结构化输入，比如："狂热": 10%）
  - 态度本质上是一个数字（比如-1～-0.7是很不认同，0.7～1是非常认可）。态度越大，以后评论的概率越高（在每个态度区间内，可能得用比较skewed的distribution，不能uniform，当然也不要太skewed）。对于普通用户（态度=0），评论概率就是随机的。
- 综合来说，数据库包括人类用户信息、帖子信息、评论信息、AI用户信息
  - 帖子信息主要来源于人类用户。
  - 评论信息维护几个字段：
    - 评论时间
    - 评论方（人类、AI）
    - 评论者userid
    - 如果评论方是AI，则有态度（这个态度与AI的设定吻合）
    - 评论层级：l1、l2
    - 回复评论的id：如果是l1，则没有；如果l2，则是l1
- 具体的逻辑为：
  - 用户发帖，生成l1评论
    - 根据AI用户里有的态度种类，每个类别生成n条评论
    - 生成的评论包含评论内容（文字）和态度，然后再根据态度强度分配给对应的AI用户，然后保存进数据库
  - l1评论发散
    - 根据帖子内容、态度、参考l1评论，生成n条评论
    - 生成的评论依然包含文字内容和态度，然后再进行分配AI用户（确保不要重复）
  - 生成l2评论
    - 根据：帖子内容，l1评论，l1评论是否来自人类用户，态度，每个类别生成n条评论
    - 参考生成l1评论
  - l2评论发散
    - 参考l1评论发散，同时包含l1评论是否来自人类用户）

## 总结
- AI用户态度是不变的，每个AI用户也并没有相关经历
- 但是每条评论是可以指派给每个特定AI用户的（通过这种反向分配的策略，减少AI的互动量，降低交互成本）
