# InfluAI 评论生成测试工具

## 概述

这个测试工具用于测试InfluAI的评论生成逻辑，包括所有相关的方法和功能。

## 文件说明

- `test_comment_generation.py` - 主要的测试脚本
- `run_test.py` - 便捷的运行脚本
- `README.md` - 使用说明

## 使用方法

### 方法一：快速测试（推荐）

```bash
cd backend/test
python quick_test.py
```

**特点**：
- 无需交互，直接运行
- 使用本地变量配置测试参数
- 快速验证所有功能

### 方法二：完整测试脚本

```bash
cd backend/test
python test_comment_generation.py
```

**特点**：
- 支持用户交互选择模板和输入内容
- 更详细的测试过程显示
- 适合深入测试和调试

### 方法三：使用便捷脚本

```bash
cd backend/test
python run_test.py
```

### 方法四：从项目根目录运行

```bash
python backend/test/quick_test.py
```

## 测试配置

### 快速测试配置

在 `quick_test.py` 中修改以下变量：

```python
# 测试配置
TEMPLATE_ID = 1  # 模板ID：1=STAR, 2=INFLUENCER, 3=CASTER
POST_CONTENT = "今天天气真好，心情也很棒！"  # 测试帖子内容
```

### 完整测试配置

在 `test_comment_generation.py` 的 `main()` 函数中修改：

```python
TEST_CONFIG = {
    "template_id": 1,  # 指定模板ID，None表示使用第一个可用模板
    "post_content": "今天天气真好，心情也很棒！"  # 测试用的帖子内容
}
```

## 测试流程

1. **加载用户模板** - 从数据库加载所有可用的用户模板
2. **选择模板** - 使用配置的模板ID或默认第一个模板
3. **设置帖子内容** - 使用配置的帖子内容
4. **创建测试用户** - 自动创建测试用户
5. **执行测试** - 依次测试所有评论生成相关的方法

## 测试内容

### 1. 帖子统计数据预测
- 测试 `predict_post_stats` 方法
- 预测新增粉丝数、评论数、点赞数

### 2. 一级种子评论生成
- 测试 `generate_lv1_seeds` 方法
- 生成6种态度类型的种子评论

### 3. 评论扩展
- 测试 `expand_lv1_comments` 方法
- 基于种子评论生成批量变体

### 4. 评论点赞数预测
- 测试 `predict_comment_likes` 方法
- 预测评论的点赞数

### 5. 完整帖子服务
- 测试 `PostService` 类
- 测试完整的评论生成流程

## 注意事项

1. **环境要求**：
   - 确保数据库已配置并运行
   - 确保API密钥已配置
   - 确保所有依赖已安装

2. **测试数据**：
   - 测试会自动创建测试用户
   - 测试完成后可以手动清理测试数据

3. **错误处理**：
   - 测试过程中如果出现错误，会显示详细的错误信息
   - 可以使用 Ctrl+C 随时中断测试

4. **日志输出**：
   - 测试过程会输出详细的日志信息
   - 可以通过日志了解每个步骤的执行情况

## 故障排除

### 常见问题

1. **数据库连接失败**
   - 检查数据库是否运行
   - 检查数据库配置是否正确

2. **API调用失败**
   - 检查API密钥是否配置
   - 检查网络连接是否正常

3. **模块导入失败**
   - 确保在正确的目录下运行
   - 检查Python路径是否正确

import logging
