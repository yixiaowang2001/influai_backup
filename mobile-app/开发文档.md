# Mobile App 开发文档（Swift / Android 方案）

## 目标
- 重构现有前后端为 iOS App（Swift）或 Android App（Kotlin）
- 保留完整功能：用户管理、模板、帖子、评论、点赞、AI 评论生成、实时更新
- 本地优先：核心业务与数据在 App 内运行，仅保留大模型网络调用

## 现状要点（对齐现有项目）
- 现有后端：FastAPI + SQLAlchemy + Celery/Redis + LLM 调用
- 现有前端：单页 Web（HTML + JS），通过 REST + WebSocket 与后端交互
- 数据库：默认本地 MySQL，可回退 SQLite

## 总体迁移策略
1) App 内实现“本地服务层”，替代 HTTP 后端
2) 数据层迁移到 iOS 本地数据库
3) 异步任务替换为本地任务队列/后台任务
4) WebSocket 推送替换为本地事件通知机制
5) 仅保留 LLM 网络调用（注意密钥安全与计费控制）

## 任务清单（通用）

### 1. 项目基架
- 创建 iOS 工程（Swift + SwiftUI）
- 搭建模块结构：UI / Domain / Data / Network
- 基础导航与页面框架（账号选择 -> 时间线 -> 详情）

### 2. 数据模型与本地数据库
- 设计本地数据模型：UserTemplate、HumanUser、AIUser、Post、Comment
- 选型本地数据库（CoreData / SQLite / Realm 其一）
- 数据迁移与初始化（从用户模板 JSON 初始化）
- CRUD 能力与索引策略（按 createdAt、postId 等）

### 3. 本地服务层（替代后端 API）
- 用户管理服务：创建用户、设置当前用户、删除用户
- 模板服务：加载模板、列表查询
- 帖子服务：创建帖子、列表、点赞
- 评论服务：创建评论、列表、点赞
- 统计服务：评论数与点赞统计

### 4. AI 模块迁移
- LLM 调用封装（网络层）
- 提示词管理与解析（JSON 解析、容错）
- 预测与生成流程：帖子统计、评论生成
- 生成任务状态管理（进度与失败处理）

### 5. 异步与任务调度
- 评论生成任务队列（替代 Celery）
- 进度回调与状态持久化
- 失败重试策略与可中断控制

### 6. 实时更新机制
- App 内事件总线/通知中心替代 WebSocket
- 新帖、评论、点赞状态同步刷新
- 详情页与时间线状态联动

### 7. UI 重构
- 账号选择页（含删除确认）
- 模板选择页
- 时间线与详情页
- 评论输入与发布
- 交互状态与错误提示

### 8. 安全与配置
- API Key 管理（避免硬编码）
- 运行环境区分（开发/生产）
- 请求超时与错误处理统一化

### 9. 测试与验证
- 关键业务流程测试
- 离线与弱网场景
- 数据一致性与任务恢复

### 10. 发布与运行
- 真机调试流程
- 证书与签名
- TestFlight 内测（可选）

## Android 方案（Kotlin）

### 技术栈
- 语言：Kotlin
- UI：Jetpack Compose
- 架构：MVVM + Repository
- 异步：Kotlin Coroutines + Flow
- 本地数据库：Room（SQLite）
- 依赖注入：Hilt（可选）
- 网络：OkHttp + Retrofit（仅 LLM 调用）

### 工程与环境
- IDE：Android Studio（必须）
- 构建工具：Gradle
- 测试设备：Android 模拟器或真机

### 模块映射（对齐现有后端）
- Data 层：Room 实体与 DAO（Post、Comment、User、Template）
- Domain 层：服务/用例（创建帖子、生成评论、点赞、统计）
- UI 层：Compose 页面（用户选择、模板选择、时间线、详情）
- 任务队列：本地协程队列 + 持久化任务表（替代 Celery）
- 推送机制：App 内事件流（Flow / SharedFlow）替代 WebSocket

### 关键实现清单
- 用户与模板初始化流程（从 JSON 种子数据导入）
- 发帖后异步生成评论（本地任务队列）
- 评论逐步投递（按时间间隔插入本地 DB + UI 订阅刷新）
- 错误与重试策略（任务失败标记、指数退避）

### 实现步骤与 UI 计划（参考现有 Web 逻辑）

#### 0. 环境与基架
1) 安装 Android Studio + Android SDK + 模拟器镜像。
2) 新建 Kotlin + Jetpack Compose 项目（单模块）。
3) 定义基础依赖：Compose BOM、Room、Coroutines、Lifecycle、Navigation。

#### 1. 数据模型与本地数据层
1) 定义 Entity：HumanUser、UserTemplate、AIUser、Post、Comment。
2) 设计 DAO：列表查询、按帖子ID取评论、点赞更新、评论数统计。
3) 本地初始化：导入模板 JSON，创建基础数据。

#### 2. 业务服务层（本地）
1) UserService：用户创建/删除/设置当前用户。
2) PostService：发帖、时间线读取、点赞、评论数维护。
3) CommentService：发评论、按时间/点赞排序。
4) TaskService：异步评论生成任务队列（本地协程 + 任务表）。

#### 3. UI 结构与导航
1) 账号选择页（含删除确认弹窗）。
2) 用户名输入页 -> 模板选择页。
3) 时间线页（帖子列表 + 底部发布框）。
4) 帖子详情页（评论列表 + 排序下拉 + 评论输入框）。

#### 4. UI 组件映射
- 顶部导航：返回账号选择/时间线。
- 帖子卡片：作者、时间、内容、评论数、点赞数。
- 评论项：作者、时间、内容、点赞按钮。
- 弹窗：删除确认、错误提示、成功提示。

#### 5. 状态管理与渲染
1) AppState：当前用户、当前视图、当前帖子、排序方式。
2) ViewModel：User/Template/Post/Comment 各自维护状态流。
3) UI 订阅 Flow/State，自动刷新列表与计数。

#### 6. 异步评论生成（本地模拟）
1) 发帖后启动任务：生成评论 -> 分批写入 DB。
2) 每批写入后触发 UI 刷新（类似推送体验）。

#### 7. 后续扩展（可选）
1) 接入 LLM 实际生成与重试。
2) 后台保活与通知策略（如需）。
